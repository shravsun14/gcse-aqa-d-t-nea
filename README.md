# GCSE AQA Design & Technology NEA Project

Raspberry Pi Smart Plant Feeder which provides a web portal and shows options to enable automatic watering, manually water the plant and turn on/off the UV lights.

Also includes a Captive Portal which activates when there is no Wi-Fi. It will broadcast a network which any mobile device can connect to and type their Wi-Fi details. Then the Plant Feeder will restart and the Wi-Fi will be connected, allowing the user to visit plant.shravsun.com from anywhere in the world.
